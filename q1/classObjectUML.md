## Properties
| Property | Data Type | Description |
|---|---|---|
| Name | String | Name of the fragrance |
| Brand | String | Brand of the fragrance |
| Projection | String | How strong is the fragrance's scent |
| Size | Int | How much ml can your fragrance hold |
## Methods
| Method | Description |
|---|---|| | |

| Spray | Spray the fragrance on yourself |
| Smell | Smell the fragrance by smelling its cap |

## Design Explanation
### Why did you choose this class?
- I chose this class since it's a class I know will be very fun, but not only did I choose it because it's fun, but because I know I'll be able to learn a lot.
### Which property is the most important? Why?
- The name, if the fragrance doesnt have a name, how will you be able to identify it, many brands have many fragrances, many fragrances haf similar projections, and almost all fragrances follow the usual 100ml size.
### Which method is the most useful? Why?
- The spray method, since a fragrance is supposed to be sprayed on yourself and to be smnelt by others, so what is it's use if it is only smelled by yourself.
